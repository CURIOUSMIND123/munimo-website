📥 Data Import — Migrate from any accounting software
Coming from Tally, Zoho Books, QuickBooks, Vyapar, Busy, Marg, Khatabook or plain Excel? Export your data as CSV there and import it here — whatever the columns are named. The importer auto-detects which of your columns is which and lets you fix any it gets wrong, so you do not have to reformat the file first. Dates and amounts in any common format are understood. Duplicates are skipped automatically — running an import twice is safe.
Step 1 — What are you importing?
The template is optional — your file can use any column names. Downloading it just shows you which details this ERP can store.
Step 2 — Choose your CSV file (any format)
Step 3 — Match your columns
We matched your file's columns to this ERP's fields automatically. Check the matches below and correct any that are wrong. Leave a field on “— Don't import —” if your file doesn't have it.
